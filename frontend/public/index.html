Blueprint de Despliegue: Docker Desktop → Render & Firebase
1. Local en Docker Desktop (`docker-compose.yml`)
Contenedores activos: nexuspf-db (PostgreSQL 16 en puerto 5440), nexuspf-api (Backend + MCP en puerto 4400) y nexuspf-web (Frontend en puerto 3400).
2. Publicación en Render (`render.yaml` incluido)
Conecta el repositorio de GitHub NexusPF_CRM en Render → New Blueprint Instance. Crea automáticamente la base de datos PostgreSQL 16 administrada y los servicios web.
3. Publicación en Firebase (`firebase.json` incluido)
Configurado para Firebase Hosting / App Hosting en el frontend estático/SSR, Firebase Auth para SSO del equipo y Firestore para notificaciones en tiempo real.
